# Szablony maili (Supabase Auth)

Wklej w: Supabase → projekt → Authentication → Emails → **Templates**.
Szablony generuje `node supabase/email-templates/build.mjs` (wspólny wygląd w `build.mjs`).

| Szablon w Supabase | Plik | Temat (Subject) |
|---|---|---|
| Confirm signup | `confirm-signup.html` | Potwierdź konto w LSO App |
| Reset password | `reset-password.html` | Zmiana hasła w LSO App |
| Change email address | `change-email.html` | Potwierdź nowy adres e-mail w LSO App |

Ikona: `https://lsoapp.com/email-icon.png` (192 px, repo lso-landing/public).
